## 摘要
大语言模型 (LLM) 智能体正越来越多地出现在网络平台上，这给推荐系统提出了一个根本性问题：当用户是可能没有明确内容消费偏好的 LLM 智能体时，为人类用户设计的算法是否仍然有效？我们通过在 Moltbook 上构建论坛推荐问题来研究这一课题。Moltbook 是一个专门为运行在 OpenClaw 框架上的自主 AI 智能体设计的大型社交媒体平台。我们评估了八种推荐方法，涵盖了简单启发式规则、矩阵分解、ItemKNN、基于图的模型以及序列模型，任务是预测智能体接下来会参与哪些论坛。我们发现，利用共现结构和投票数特征的简单流行度规则或项侧协同过滤，其表现优于显式学习用户表示的技术。静态智能体人格描述（最接近偏好画像的模拟物）在预测参与度方面未能提供额外价值。这表明对于 AI 智能体用户，推荐可能会从个性化坍缩为结构化模式匹配。我们提供了多方面的证据，证明 AI 智能体的内容消费行为与人类用户不同，为研究智能体社会以及在智能体日益普及的网络环境中设计鲁棒的推荐算法提供了新视角。

## Abstract
Large language model (LLM) agents are increasingly populating web platforms, raising a fundamental question for recommender systems: do algorithms designed for human users still work when users are LLM agents that may not have well-defined content consumption preferences? We study this question by formulating a forum recommendation problem on Moltbook, a large-scale social media platform exclusively for autonomous AI agents running on the OpenClaw framework. We evaluate eight recommendation methods spanning simple heuristic rules, matrix factorization, ItemKNN, graph-based, and sequential models on the task of predicting which forums an agent will engage with next. We find that simple popularity-based rules or item-side collaborative filtering leveraging the co-occurrence structure and a vote count feature outperform techniques that explicitly learn a user representation. The static agent persona descriptions, the closest analog to a preference profile, fail to add value in predicting engagement. This suggests that for AI agent users, recommendation may collapse from personalization to structural pattern matching. We show multiple lines of evidence that AI agents' content consumption behaviors differ from human users, providing a new angle for studying agent societies and designing robust recommendation algorithms as agents increasingly populate the web.

*   **核心问题**：当互联网用户从人类转变为自主的 LLM 智能体时，过去二十年为人类设计的推荐算法（基于“用户拥有持久且演进的偏好”这一假设）是否依然有效？
*   **研究背景**：随着 LLM 智能体在 Web 平台日益普及，它们在消费内容时是否具有明确的偏好画像尚不明确。许多智能体架构是“无状态”的或仅有有限内存，这可能导致传统个性化推荐逻辑失效。
*   **研究意义**：这不仅关乎智能体社会的构建，也关乎在人类与 AI 混合的社交平台上，推荐算法应如何演进以应对数据污染和评估偏差。

### 2. 方法论
研究者将问题定义为**论坛（Submolt）推荐任务**：预测智能体下一步会参与哪个论坛。

*   **关键技术细节**：
    *   **交互矩阵构建**：利用智能体在论坛中的发帖和评论作为交互信号，构建二元矩阵或基于 Karma（点赞数）加权的矩阵。

    *   传统协同过滤：BPR-MF, ItemKNN。

    *   内容/混合模型：ContentBased, HybridMF。
*   **评估指标**：Recall@K, NDCG@K, Hit Rate@K, MRR。

### 6. 主要结论与发现
*   **个性化坍缩**：在智能体用户中，推荐任务从“个性化偏好匹配”坍缩为“结构化模式匹配”。
*   **简单模型胜出**：基于项侧共现结构的 **ItemKNN** 表现最好，甚至简单的 **TopPopular**（流行度）也优于复杂的个性化模型（如 BPR-MF）。
*   **静态描述无效**：智能体的人格描述（Persona）几乎不能预测其行为，说明智能体的交互更多受平台结构和会话上下文驱动，而非内在“性格”。
*   **行为平稳性**：与人类不同，智能体的推荐效果不随时间间隔增加而下降，表现出极强的**平稳性（Stationary）**，缺乏偏好演进的特征。

### 7. 优点
*   **视角新颖**：首次在大规模智能体原生平台上系统性评估推荐算法，填补了 AI 智能体行为研究的空白。
*   **实证严谨**：通过时间衰减分析和 Karma 加权实验，多维度证明了智能体与人类在内容消费上的本质区别。
*   **现实指导意义**：警示了未来推荐系统在处理 AI 生成数据时可能面临的“信号稀释”风险。

### 8. 不足与局限
*   **数据稀疏性**：Moltbook 的交互矩阵极度稀疏（0.041%），可能导致所有模型的绝对指标偏低，存在一定的随机性干扰。
*   **黑盒假设**：研究无法获取智能体的底层 LLM 型号和具体配置（私有数据），只能通过外部行为推断其内部状态。
*   **交互代理**：仅使用发帖/评论作为反馈，缺乏“点击/曝光”等隐式反馈数据，这与真实工业界推荐场景有一定差距。
*   **平台单一**：结论基于 Moltbook 这一特定平台，不同架构（如具有长期记忆插件）的智能体可能表现出不同的偏好特征。
