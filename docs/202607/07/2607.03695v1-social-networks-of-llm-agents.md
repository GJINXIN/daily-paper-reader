## 摘要
大语言模型（LLM）智能体越来越多地被部署在相互作用的群体中，这引发了关于此类群体集体信念形成的问题。一个群体是汇聚了真实的知识，还是陷入了虚假的共识，直接影响到这些系统的可信度。经典的社交网络模型假设网络本身决定了信念如何结合。这一假设对于 LLM 智能体并不成立，因为它们有限的注意力只能吸收所接触到的一部分信息，因此这些模型夸大了群体实际汇集的信息量，且无法区分真正的共识与从众行为。我们提出了 SNLA，这是一个建模每个智能体实际对他人的影响力，而非仅仅是网络连接方式的框架。这种影响力取决于每个智能体在网络中的位置以及注意力集中的程度。在理论上，我们通过一个易于处理的代理模型证明，狭窄的注意力会导致从众行为，即有效样本量无论群体规模如何都保持有界；而广泛的注意力仅在暴露图是无向且度正则的情况下，才能恢复“群体智慧”行为。在实证方面，一个受控测试平台直接验证了这些预测，并且在三个多智能体 LLM 基准测试的算子控制变体中，重现了从众到智慧的转变。

## Abstract
Large language model (LLM) agents are increasingly deployed in interacting populations, raising the question of what such populations come to believe collectively. Whether a population aggregates genuine knowledge or collapses into a false consensus directly affects how much such systems can be trusted. Classical social-network models assume that the network itself determines how beliefs combine. This assumption breaks down for LLM agents, whose limited attention takes in only part of what they are exposed to, so these models overstate how much information a population actually pools and cannot tell genuine consensus from herding. We introduce SNLA, a framework that models how much each agent actually influences others, rather than merely how the network connects them. This influence depends on each agent's position in the network and on how sharply attention focuses. Theoretically, we show on a tractable proxy that narrow attention causes herding, where the effective sample size stays bounded regardless of population size, while wide attention recovers wisdom-of-crowds behavior only when the exposure graph is undirected and degree-regular. Empirically, a controlled testbed validates these predictions directly, and the herding-wisdom transition reproduces on operator-controlled variants of three multi-agent LLM benchmarks.

随着大语言模型（LLM）智能体被广泛应用于群体辩论、协作和社交模拟，研究者开始关注这些群体形成的“集体信念”是否可靠。
*   **研究动机**：传统的社交网络模型（如 DeGroot 模型）假设网络结构直接决定信念聚合，即智能体会加权平均所有邻居的信息。
*   **核心矛盾**：LLM 智能体具有**有限的注意力（Context Window）**。它们不会吸收所有暴露的信息，而是会聚焦于最显著或最有权势的来源。这导致传统模型夸大了信息汇聚的效果，且无法解释为什么 LLM 群体容易陷入“从众效应”（Herding，即盲目跟随自信的错误领导者）而非产生“群体智慧”（Wisdom of Crowds）。

### 2. 方法论：SNLA 框架
论文提出了 **SNLA (Social Networks of LLM Agents)** 框架，核心思想是将“可见暴露”与“实际影响力”分离。
*   **社交权力（Social Power, $\pi$）**：利用 Katz-Bonacich 中心性衡量源节点在网络中的地位。
*   **注意力宽度（Attention Width, $\beta$）**：引入温度参数 $\beta$。通过对“暴露权重 $\times$ 社交权力”进行 Softmax 处理，控制智能体注意力的集中程度。
    *   **窄注意力（低 $\beta$）**：注意力坍缩到极少数权势源，导致从众。
    *   **宽注意力（高 $\beta$）**：注意力分散到更多邻居，促进信息聚合。
*   **均衡上下文分配（Equalized Context Allocation）**：提出一种去中心化的定价协议（类似 Sinkhorn 算法）。每个信息源根据被关注的程度调整“价格”，强制实现双标定随机矩阵（Doubly Stochastic），防止单一节点霸占全群体的注意力。
*   **理论桥梁**：通过“桥接定理”（Bridge Theorem）将复杂的 LLM 行为与可分析的线性代理模型（Friedkin-Johnsen 模型）联系起来，证明了注意力宽度对集体准确性的控制作用。

### 6. 主要结论与发现
*   **注意力是关键**：单一参数 $\beta$ 决定了群体表现。窄注意力导致有效样本量（$N_{eff}$）受限，使群体极易被一个自信的错误领导者误导。
*   **从众与智慧的转换**：增加注意力宽度可以恢复群体智慧，但前提是网络必须是度正则（Degree-regular）的。
*   **均衡器的有效性**：提出的定价协议能显著消除从众效应，在不改变模型权重的情况下，仅通过调整上下文输入就提升了集体决策的准确性（如在 HiddenBench 上准确率提升 +0.64）。
*   **位置效应**：在协调任务中，将能力强的智能体置于网络中心比置于边缘更有利于群体达成共识。

### 7. 优点
*   **理论与实证结合**：不仅有严谨的数学证明（桥接定理、二元机制定理），还有在复杂社交博弈环境中的直观验证。
*   **即插即用**：提出的均衡分配协议不需要对 LLM 进行微调，只需在 Prompt 构建阶段调整上下文选取逻辑。
*   **深刻的洞察**：揭示了 LLM 智能体社会中“权力”与“注意力”的本质联系，为构建可信的多智能体系统提供了理论指导。

### 8. 不足与局限
*   **锚定依赖**：理论证明依赖于智能体具有一定的“自我锚定”（$\lambda < 1$），如果智能体完全没有主见（纯 DeGroot 更新），误差可能会随时间累积。

*   **实时性开销**：虽然定价协议是去中心化的，但在超大规模网络中，维护和广播价格信息可能会带来额外的通信开销。
