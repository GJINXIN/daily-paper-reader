## 摘要
本文研究了多智能体具身问答（MA-EQA），其目标是针对机器人团队在长时程内所观察到的内容进行提问。与现有的强调感知、通信或计算性能指标的边缘资源管理方法不同，MA-EQA 强调存储质量。为了应对这一范式转变，我们提出了一种基于生成对抗考试（GAE）的存储质量（QoM）模型，该模型利用前向模拟来评估存储检索，并使用所得的考试分数来计算 QoM 值。随后，我们提出了以存储为中心的功率分配（MCPA）方案，旨在通信资源约束下最大化 QoM 函数。通过渐近分析发现，发射功率与 GAE 错误概率成正比，从而实现了向高 QoM 机器人的资源倾斜。广泛的实验表明，在各种场景下，MCPA 在多种指标上均优于大量基准方法，取得了显著提升。

## Abstract
This paper considers multi-agent embodied question answering (MA-EQA), which aims to query robot teams on what they have seen over a long horizon. In contrast to existing edge resource management methods that emphasize sensing, communication, or computation performance metrics, MA-EQA emphasizes the memory qualities. To cope with this paradigm shift, we propose a quality of memory (QoM) model based on generative adversarial exam (GAE), which leverages forward simulation to assess memory retrieval and uses the resulting exam scores to compute QoM values. Then we propose memory centric power allocation (MCPA), which maximizes the QoM function under communication resource constraints. Through asymptotic analysis, it is found that the transmit powers are proportional to the GAE error probability, thus prioritizing towards high-QoM robots. Extensive experiments demonstrate that MCPA achieves significant improvements over extensive benchmarks in terms of diverse metrics in various scenarios.

### 2. 方法论
*   **核心思想**：提出“以存储为中心”的理念，通过**生成对抗考试（GAE）**来量化存储质量（QoM），并据此优化功率分配。

    *   **GAE（生成对抗考试）**：
        1.  **试点上传**：机器人先上传极少量的采样数据（1%-10%）。
        2.  **试卷生成**：边缘服务器利用视觉语言模型（VLM）对采样数据生成“问题-答案”对。
        3.  **模拟测试**：用服务器现有的历史存储去回答这些问题。如果回答错误，说明该机器人拥有的新数据具有高价值。
    *   **QoM（存储质量）模型**：将 GAE 的得分（错误率）与通信速率相结合，构建一个显式的目标函数，代表增加该机器人数据后预期带来的准确率提升。
    *   **MCPA（以存储为中心的功率分配）算法**：
        *   在总功率约束下，最大化 QoM 函数。
        *   利用**逐次优化（Successive Optimization）**技术将非凸问题转化为凸子问题求解。
        *   **渐近分析发现**：最优发射功率与 GAE 的错误概率成正比，即系统会自动向拥有“服务器不知道的信息”的机器人倾斜资源。

### 6. 主要结论与发现
*   **性能领先**：MCPA 在问答准确率上达到 **95.35%**，显著优于 MaxRate（61.69%）和 MaxCov（86.09%）。
*   **质量胜过数量**：通信速率最高或感知覆盖最广并不意味着问答最准。如果上传的是冗余信息，高带宽反而造成资源浪费。
*   **资源分配逻辑**：功率分配应与“知识缺口”挂钩。GAE 能够有效识别哪些机器人看到了服务器尚未掌握的关键场景。

### 7. 优点
*   **指标创新**：成功将高层逻辑推理任务（EQA）的需求转化为底层的物理层资源分配问题。
*   **前向模拟机制**：通过 GAE 解决了“预知未来问题”的难题，使系统具备了主动筛选价值信息的能力。
*   **理论支撑**：提供了渐近最优解的解析式，揭示了功率分配与错误概率之间的直观联系。

### 8. 不足与局限
*   **试点开销**：GAE 需要先进行试点数据上传，虽然比例较小，但在极度受限的带宽下仍存在初始延迟。
*   **模型依赖**：系统性能高度依赖于 VLM 和 LLM 的理解能力，若基础模型产生幻觉，GAE 的评分可能失效。
*   **场景单一**：实验主要在 CARLA 城市道路场景进行，对于室内、森林等更复杂或非结构化环境的泛化性有待验证。
*   **计算延迟**：虽然通信时间是主要瓶颈，但大规模智能体并行执行 GAE 时的服务器端计算压力未被深入讨论。
