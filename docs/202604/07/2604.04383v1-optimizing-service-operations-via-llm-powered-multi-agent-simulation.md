## 摘要
服务系统的性能取决于参与者对设计选择的反应，但由于人类行为的复杂性，对这些反应进行建模非常困难。我们引入了一种大语言模型驱动的多智能体仿真（LLM-MAS）框架，用于优化服务运营。我们将该问题建模为具有决策依赖型不确定性的随机优化问题：设计选择被嵌入到提示词中，并塑造了相互作用的大语言模型驱动智能体所产生结果的分布。通过在提示词中嵌入关键数值信息并从大语言模型生成的文本中提取这些信息，我们将这种不确定性建模为一个受控马尔可夫链。我们开发了一种在线轨迹学习算法，在单次仿真运行中，同时构建零阶梯度估计并更新设计参数，以优化稳态性能。我们还结合了方差缩减技术。在可持续供应链的应用中，我们的方法优于基准方法，包括黑盒优化以及将大语言模型用作数值求解器或角色扮演系统设计者的方法。一项基于真实行为数据的最优竞赛设计案例研究表明，LLM-MAS 既是已知设计的高性价比评估器，也是一种能够发现传统方法所忽略的优秀设计的探索性工具。

## Abstract
Service system performance depends on how participants respond to design choices, but modeling these responses is hard due to the complexity of human behavior. We introduce an LLM-powered multi-agent simulation (LLM-MAS) framework for optimizing service operations. We pose the problem as stochastic optimization with decision-dependent uncertainty: design choices are embedded in prompts and shape the distribution of outcomes from interacting LLM-powered agents. By embedding key numerical information in prompts and extracting it from LLM-generated text, we model this uncertainty as a controlled Markov chain. We develop an on-trajectory learning algorithm that, on a single simulation run, simultaneously constructs zeroth-order gradient estimates and updates design parameters to optimize steady-state performance. We also incorporate variance reduction techniques. In a sustainable supply chain application, our method outperforms benchmarks, including blackbox optimization and using LLMs as numerical solvers or as role-playing system designers. A case study on optimal contest design with real behavioral data shows that LLM-MAS is both as a cost-effective evaluator of known designs and an exploratory tool that can uncover strong designs overlooked by traditional approaches.

### 2. 方法论
*   **核心思想**：将系统设计建模为**具有决策依赖不确定性的随机优化问题**。设计参数 $\theta$ 被嵌入到智能体的提示词（Prompt）中，通过影响 LLM 生成 Token 的概率分布，进而改变智能体的行为和系统最终产出。
*   **关键技术细节**：
    *   **受控马尔可夫链（CMC）**：将 LLM-MAS 的动态过程建模为 CMC。系统状态 $\xi$ 由智能体的观察、沟通和行动组成，状态转移受设计参数 $\theta$ 控制。
    *   **在线轨迹学习算法（OTL）**：为了解决 LLM 推理延迟高、成本贵的问题，OTL 在单次仿真轨迹中同时进行梯度估计和参数更新。它采用双时间尺度（Two-timescale）方案，确保算法在移动的分布中收敛。
    *   **零阶梯度估计**：由于 LLM 的概率分布不可导且黑盒化，采用基于随机同步扰动的零阶方法估计梯度。
    *   **方差缩减技术**：引入了**引导扰动（GP）**（利用性能函数的显式结构）和**残差反馈（RF）**（利用历史迭代信息）来降低仿真噪声。

    2.  **创新竞赛设计**：优化竞赛的入场费、保留价和共享奖金，以最大化参赛者的总努力程度。
*   **基准方法（Benchmarks）**：
    *   **贝叶斯优化（BO）**：将问题视为黑盒优化。

    *   **LLM-as-a-Designer**：让 LLM 扮演决策者角色，根据仿真结果直观调整设计。

### 5. 实验数量与充分性
*   **实验规模**：
    *   供应链实验对比了 6 种不同的优化路径，运行了数千次 LLM 查询。

*   **充分性与公平性**：实验设计较为充分，不仅涵盖了数值优化性能的对比，还通过人类行为数据验证了 LLM 仿真的**行为保真度（Behavioral Fidelity）**。对比实验考虑了随机性影响，并使用了方差缩减技术来确保结果的客观性。

### 6. 主要结论与发现
*   **性能优越性**：提出的 OTL 算法在收敛速度和最终目标函数值上均显著优于 BO 和直接使用 LLM 求解的方法。
*   **行为一致性**：LLM-MAS 能够很好地复制人类在实验室中的非理性行为（如风险规避、损失厌恶），而这些行为是传统博弈论模型无法准确预测的。
*   **发现新设计**：在竞赛设计中，LLM-MAS 发现了一种“中等入场费、低保留价”的方案，其表现优于博弈论推导的最优解，证明了其作为探索性工具的价值。
*   **互补性**：LLM 并非传统运筹学（OR）方法的替代品，而是作为一种强大的仿真组件，与严谨的数值优化算法结合才能发挥最大效用。

### 7. 优点
*   **桥接理论与现实**：通过 LLM 捕捉非结构化信息（如广告文本、沟通对话）对决策的影响，放宽了传统模型过于理想化的假设。
*   **高性价比**：相比昂贵的人类实验，LLM-MAS 提供了一个低成本、可重复的“硅基沙盒”。
*   **可解释性**：LLM 生成的推理轨迹（Reasoning Traces）为设计者提供了智能体决策背后的逻辑，这是强化学习（RL）等黑盒模型难以提供的。

### 8. 不足与局限
*   **维度灾难**：作为零阶优化方法，当设计参数 $\theta$ 的维度非常高时，收敛效率可能会下降。
*   **模型偏差风险**：仿真结果高度依赖于底层 LLM 的质量。如果 LLM 存在系统性偏差，优化出的设计可能在现实中失效。
*   **查询成本**：尽管 OTL 优化了效率，但对于超大规模智能体系统，LLM 的推理延迟和 Token 成本仍是实际部署的障碍。
*   **应用限制**：目前主要集中在稳态性能优化，对于极度动态或瞬态系统的建模能力尚待进一步验证。
