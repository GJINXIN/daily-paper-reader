## 摘要
使用大语言模型（LLM）的多智能体系统在多个领域展现出卓越的能力。然而，当前的智能体通信面临输出冗长的问题，这会导致上下文过载并增加计算成本。尽管现有方法侧重于从发送方压缩消息，但它们难以适应不同的接收方并识别关键信息。人类交流中的一种有效方式是允许听者中断并表达观点或寻求澄清。受此启发，我们提出了一种可中断的通信框架，允许正在倾听的智能体中断当前的发言者。通过提示实验，我们发现当前的 LLM 往往过度自信，在获取足够信息之前就进行中断。因此，我们提出了一种学习方法，根据估计的未来奖励和成本来预测合适的中断点。我们在多种多智能体场景中评估了该框架，包括双智能体文字猜词游戏、三智能体会议调度和三智能体辩论。实验结果表明，与基准方法相比，我们的 HANDRAISER 在保持相当或更优任务性能的前提下，将通信成本降低了 32.2%。这种学习到的中断行为还可以推广到不同的智能体和任务中。

## Abstract
Multi-agent systems using large language models (LLMs) have demonstrated impressive capabilities across various domains. However, current agent communication suffers from verbose output that overload context and increase computational costs. Although existing approaches focus on compressing the message from the speaker side, they struggle to adapt to different listeners and identify relevant information. An effective way in human communication is to allow the listener to interrupt and express their opinion or ask for clarification. Motivated by this, we propose an interruptible communication framework that allows the agent who is listening to interrupt the current speaker. Through prompting experiments, we find that current LLMs are often overconfident and interrupt before receiving enough information. Therefore, we propose a learning method that predicts the appropriate interruption points based on the estimated future reward and cost. We evaluate our framework across various multi-agent scenarios, including 2-agent text pictionary games, 3-agent meeting scheduling, and 3-agent debate. The results of the experiment show that our HANDRAISER can reduce the communication cost by 32.2% compared to the baseline with comparable or superior task performance. This learned interruption behavior can also be generalized to different agents and tasks.

### 论文总结：语言驱动的多智能体通信中的学习中断机制

#### 1. 核心问题与整体含义（研究动机和背景）
随着大语言模型（LLM）在多智能体系统（MAS）中的广泛应用，系统面临着**通信效率低下**的严峻挑战。当前的智能体通信通常是“回合制”且“全量发送”的，导致：
*   **上下文过载**：冗长的消息迅速填满上下文窗口，降低模型推理质量。
*   **计算成本高昂**：生成大量无用 Token 增加了推理开销和延迟。
*   **缺乏灵活性**：现有的压缩方法多从“发送方”入手，难以兼顾不同“接收方”对信息的需求差异。

本研究受人类对话中“中断”行为的启发，提出了一种**可中断通信框架**。其核心目标是让听者（接收方）能够根据当前已接收的信息片段，动态决定是否中断发言者，从而在保证任务完成质量的前提下，最大限度地减少通信冗余。

#### 2. 方法论：核心思想与关键技术
论文提出了名为 **HANDRAISER** 的学习框架，其核心流程如下：

*   **可中断通信协议**：发言者将消息切分为固定大小的块（Chunks）流式发送。听者在接收每个块后，判断是否发出中断信号。一旦中断，发言者停止生成，听者立即响应。
*   **收益评估（Payoff Estimation）**：为了确定最佳中断点，研究者定义了中断的“收益”：
    *   **成本变化 ($\Delta cost$)**：中断节省的 Token 数与后续对话可能增加的 Token 数之差。
    *   **性能变化 ($\Delta perf$)**：中断后的任务成功率与不中断时的成功率之差。
    *   **正向收益标准**：只有当 $\Delta cost < 0$（成本降低）且 $\Delta perf \geq 0$（性能不下降）时，该中断点才被视为理想点。
*   **树状采样与标注（Tree Sampling）**：由于中断会改变后续对话轨迹，研究者使用树状采样模拟不同中断点后的多种可能性，通过多次 Rollout 估算期望收益，并据此标注训练数据。
*   **学习中断行为**：利用标注数据对 LLM（如 Llama-3.1）进行监督微调（SFT），使其学会预测具有高收益的中断时机，克服了原生模型“过度自信”和“过早中断”的问题。

论文在三个具有代表性的多智能体场景中进行了评估：

    2.  **会议调度 (Meeting Scheduling)**：三方智能体在私有约束下协商会议时间。

*   **后端模型**：使用了 Llama-3.1 (8B/70B/405B)、GPT-4o 和 Gemini-2.0-flash。

*   **采样开销**：论文提到树状采样具有一定的计算成本，但属于一次性离线训练成本。

#### 5. 实验数量与充分性
*   **实验规模**：每个场景包含 50 到 100 个测试案例，每组设置运行 3 次取平均值。
*   **覆盖面**：涵盖了 2 智能体和 3 智能体系统，测试了不同规模（8B 到 405B）和不同厂商（Meta, OpenAI, Google）的模型组合。
*   **消融与分析**：进行了跨任务泛化实验（在一个任务训练，另一个任务测试）、跨模型泛化实验、块大小（Chunk Size）敏感度分析以及中断阈值分析。
*   **评价**：实验设计较为全面，对比了发送方压缩和接收方中断两种范式，验证了方法的鲁棒性和通用性。

#### 6. 主要结论与发现
*   **显著降本**：HANDRAISER 在保持或提升任务成功率的同时，平均降低了 **32.2%** 的通信成本（在辩论场景中甚至降低了 48.9%）。
*   **克服过度自信**：原生 LLM 在 Prompt 引导下极易过早中断（认为自己懂了，其实没懂），而经过学习的 HANDRAISER 能更精准地把握信息饱和点。
*   **强泛化性**：在 Llama 上训练的中断逻辑可以直接应用于 GPT-4o 或 Gemini 驱动的系统，且在不同任务间也表现出一定的迁移能力。
*   **延迟优化**：由于减少了等待全量消息的时间，系统的端到端响应延迟也得到了理论上的优化。

#### 7. 优点
*   **视角新颖**：从“听者”角度解决通信冗余，弥补了过去仅关注“说者”压缩的不足。
*   **启发式学习**：通过树状采样模拟未来收益，解决了中断决策中“短期节省 vs 长期性能”的权衡难题。
*   **实用性强**：协议简单，易于集成到现有的流式推理 API 中。

#### 8. 不足与局限
*   **训练成本**：获取高质量中断标注数据需要大量的 Rollout 采样，对于超大规模任务可能存在算力瓶颈。
*   **超参数依赖**：块大小（Chunk Size）的选择对性能有影响，过小的块会增加推理请求频率，过大的块则降低中断的灵敏度。
*   **单向性限制**：目前主要研究单向中断，对于多智能体同时抢话（冲突处理）的复杂社交动态讨论尚处于初步阶段。
*   **文本局限**：目前仅验证了文本模态，尚未涉及多模态（如语音实时中断）场景。
