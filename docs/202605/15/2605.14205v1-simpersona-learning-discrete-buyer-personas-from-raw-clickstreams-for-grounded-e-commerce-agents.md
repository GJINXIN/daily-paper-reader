## 摘要
基于大语言模型（LLM）的网络智能体可以导航实时店面，但它们往往会坍缩为单一的“平均买家”策略，无法捕捉真实买家群体异质性和分布性的特征。现有的个性化方法依赖于手工设计的基于提示（prompt）的画像，这些画像脆弱、难以扩展、上下文效率低，且无法忠实地代表群体层面的行为。我们提出了 SimPersona，这是一个新颖的框架，它从历史流量中学习离散的买家类型，并将其作为紧凑的画像标记（persona tokens）提供给基于 LLM 的网络智能体。给定原始点击流，一种行为感知的 VQ-VAE 归纳出一个离散的买家类型空间，该空间捕捉了真实买家行为的统计结构以及特定商家的买家群体分布。为了给基于 LLM 的网络智能体提供特定行为的指导，SimPersona 将每个学习到的买家类型映射到 LLM 智能体词表中的专用画像标记，并在真实浏览轨迹上使用这些标记对智能体进行微调。在推理时，每个合成买家通过单次编码器前向传播被分配到一个学习到的买家类型，无需重新训练或针对特定商店的提示工程。对于群体层面的模拟，SimPersona 从每个商家在学习到的 VQ-VAE 码本上的经验分布中采样买家类型，并使用相应的画像标记实例化智能体，从而保留了特定商家的买家群体分布。在跨越 42 个预留实时店面的 837 万买家上进行的评估显示，SimPersona 与真实买家的转化率一致性达到 78%，在不同买家类型间表现出可解释的行为差异，并在目标导向的购物任务中优于参数量大 8 倍的基准模型。我们还发布了一个开源数据流水线，可将原始电子商务事件日志转换为买家表示和智能体训练轨迹。

## Abstract
LLM-based web agents can navigate live storefronts, yet they often collapse to a single "average buyer" policy, failing to capture the heterogeneous and distributional nature of real buyer populations. Existing personalization methods rely on hand-crafted prompt-based personas that are brittle, difficult to scale, context-inefficient, and unable to faithfully represent population-level behavior. We introduce SimPersona, a novel framework that learns discrete buyer types from historical traffic and exposes them to LLM-based web agents as compact persona tokens. Given raw clickstreams, a behavior-aware VQ-VAE induces a discrete buyer-type space that captures the statistical structure of real buyer behavior and merchant-specific buyer population distributions. To provide behavior-specific guidance to LLM-based web agents, SimPersona maps each learned buyer type to a dedicated persona token in the LLM agent vocabulary and fine-tunes the agent with these tokens on real browsing traces. At inference, each synthetic buyer is assigned to a learned buyer type with a single encoder forward pass, requiring no retraining or store-specific prompt engineering. For population-level simulation, SimPersona samples buyer types from each merchant's empirical distribution over the learned VQ-VAE codebook and instantiates agents with the corresponding persona tokens, preserving merchant-specific buyer population distributions. Evaluated on $8.37$M buyers across $42$ held-out live storefronts, SimPersona achieves $78\%$ conversion-rate alignment with real buyers, exhibits interpretable behavioral variation across buyer types, and outperforms a baseline with $8\times$ more parameters on goal-oriented shopping tasks. We further release an open-source data pipeline that converts raw e-commerce event logs into buyer representations and agent-training traces.

### 2. 方法论
SimPersona 结合了表示学习和强化学习的思想，通过以下三个核心组件实现：
*   **数据流水线**：将原始点击流（Page View, ATC, Search 等）转化为两类数据：
    1.  **买家行为表示**：一个 403 维向量，包含 16 个行为标量（如转化率、访问频率）和经过 PCA 降维的商品嵌入。
    2.  **智能体训练轨迹**：利用 LLM 将真实会话重写为导航目标，并在实时店面上回放生成 SFT（监督微调）轨迹。
*   **行为感知 VQ-VAE**：
    *   使用向量量化变分自编码器（VQ-VAE）将高维行为特征映射到 $K$ 个离散的“画像标记（Persona Tokens）”。
    *   **损失函数设计**：除了重构损失，还引入了**对比损失（Contrastive Loss）**以增强语义聚类，以及**辅助分类头**（预测参与度、探索度、购买强度）来确保画像的可解释性。
*   **两阶段监督微调（SFT）**：
    *   **第一阶段（画像锚定）**：冻结 LLM 主干，仅训练新引入的画像 Token 嵌入。使用“意图中性”的目标，强迫模型从行为模式中学习 Token 含义。
    *   **第二阶段（行动导向微调）**：解冻主干，在带有明确意图（如“去买裙子”）的轨迹上进行全参数微调。

*   **实验规模**：实验覆盖了从超大型（310 万买家）到小型（不足 1000 买家）的各类商店，具有很强的代表性。

    *   对比了 VQ-VAE 与 k-means 的聚类一致性。

### 6. 主要结论与发现
*   **高对齐度**：SimPersona 在转化率对齐（ARA）上达到了 **78%**，显著优于错配基准。
*   **分布还原**：通过 VQ-VAE 码本的经验分布，能够忠实还原特定商店的买家群体构成（JS 散度仅 0.054）。
*   **以小博大**：14B 参数的模型在复杂的购物任务中，指令遵循能力超越了 120B 的模型，尤其是在长路径的结账流程中。
*   **行为可解释性**：学习到的画像 Token 在模拟中表现出明显的行为差异（如高购买强度 Token 的转化率是低强度 Token 的百倍以上）。

### 7. 优点与亮点
*   **离散化创新**：将复杂的买家行为压缩为单个 Token，既保留了高维信息的表达力，又极大地节省了 LLM 的上下文窗口。
*   **群体分布模拟**：首次实现了不仅模拟“个人”，还能模拟整个商店“流量分布”的能力。
*   **两阶段微调策略**：有效解决了 LLM 在学习新 Token 时容易忽略语义而走“捷径”的问题。
*   **开源贡献**：提供了从原始日志到智能体轨迹的完整数据流水线工具。

### 8. 不足与局限
*   **探索行为区分度不足**：实验发现“探索度（Exploration）”维度的行为分离不够明显，可能是因为模拟环境的初始指令（给定特定类别）产生了“地板效应”。
*   **视觉信息缺失**：目前仅基于 DOM 树，忽略了影响人类决策的视觉 UI 元素。
*   **冷启动限制**：对于完全没有历史点击流数据的新商店，该框架无法直接生成画像分布。
*   **时间动态性**：未充分考虑买家行为随时间（如季节性、促销期）的演变。
